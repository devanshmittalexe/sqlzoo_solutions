# 🐸 SQLZoo Solutions

Complete solutions to all [SQLZoo](https://sqlzoo.net) exercises, written in SQL.

SQLZoo is one of the most underrated free platforms to practice SQL — no setup, no fluff, just real problems that force you to actually think.

---

## 📂 Sections Covered

| # | Section | Topics Covered |
|---|---------|---------------|
| 1 | SELECT Basics | Simple queries, WHERE, LIKE |
| 2 | SELECT from World | Filtering, expressions, subqueries |
| 3 | SELECT from Nobel | Pattern matching, ordering |
| 4 | SELECT within SELECT | Nested subqueries |
| 5 | SUM and COUNT | Aggregation, GROUP BY, HAVING |
| 6 | JOIN | INNER JOIN, multi-table queries |
| 7 | More JOIN | Complex joins, movie database |
| 8 | Using NULL | IS NULL, COALESCE, LEFT JOIN |
| 9 | Self JOIN | Self referencing tables, bus routes |

---

## 💡 What I Learned

- Writing subqueries inside WHERE, SELECT, and FROM
- Aggregating data with GROUP BY and HAVING
- Joining multiple tables cleanly
- Handling NULL values properly
- Self joins — joining a table to itself to find relationships within the same dataset
- Thinking in SQL, not just writing it

## 🚀 How to Use

Each section has its own SQL file with solutions and comments explaining the logic.

You can run these directly on [SQLZoo](https://sqlzoo.net) .
